# 個人 Profile 網站

## 1. 放素材
把自己的素材放進 `assets`：

- `background.jpg` = 網站背景
- `avatar.jpg` = 頭像
- `cover.jpg` = 音樂封面
- `music.mp3` = 音樂

## 2. 改名字
打開 `index.html`，把：

yourname

換成你的名字。

## 3. 改 TikTok
找到：

https://www.tiktok.com/

換成你的 TikTok 個人頁面。

## 4. 開網站
直接雙擊 `index.html` 即可預覽。

之後如果要放到網路上，可以使用 GitHub Pages。
